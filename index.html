Manual Order Variation Picker improves the WooCommerce admin order workflow by letting you select product attributes step by step. Choose the product, select its attributes such as color and size, and add the correct variation directly to the order.

Simple variation selection

Select attributes individually instead of searching through a long list of variation combinations.

Built for manual orders

Designed specifically for WooCommerce administrators who create or edit customer orders manually.

Stock-aware

Uses WooCommerce stock information when adding variations to the current order.

Works with WooCommerce

Supports modern WooCommerce order storage as well as the legacy order system.

How it works

  1. Open or create a manual WooCommerce order.
  2. Search for the variable product.
  3. Select the required attributes.
  4. Add the matching variation to the order.
  5. Continue using the normal WooCommerce order workflow.

Compatibility

  • WooCommerce manual order administration
  • HPOS order storage
  • Legacy WooCommerce order storage
  • Variable products with multiple attributes
